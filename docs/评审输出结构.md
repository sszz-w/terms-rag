# 评审输出结构

## 1. 输出 JSON 结构

```json
{
  "clause_id": "registered_capital",
  "clause_text": "注册资金不少于 500 万元。",
  "result": "符合",
  "reasoning": "投标文件显示注册资金为 1000 万元，满足不少于 500 万元的要求。",
  "quote": "注册资本：壹仟万元整（见营业执照副本第2页）"
}
```

## 2. 当前设计决策

1. **条款依赖关系**：条款之间可能有依赖关系，但前期不设计，后续按需扩展
2. **条款模板库规模**：大约 500+ 条，按供货范围分类
3. **引用原文定位**：希望定位到关键句及页码

## 3. 引用原文定位方案

### 3.1 核心思路

PDF 解析时不要只导出纯文本，而是导出带位置信息的结构。输入带 page 标记的段落，返回的 quote 自然能带上页码。

### 3.2 PDF 解析输出结构

```json
{
  "page": 12,
  "section": "三、资格证明文件",
  "paragraphs": [
    {
      "index": 0,
      "page": 12,
      "text": "我公司注册资本壹仟万元整，详见附件营业执照副本。"
    },
    {
      "index": 1,
      "page": 12,
      "text": "公司成立于2015年3月，具有独立法人资格。"
    }
  ]
}
```

### 3.3 实现要点

- PDF 解析阶段保留页码和章节信息
- 将带页码标记的段落作为大模型输入
- 大模型返回的 quote 字段自然包含页码定位
